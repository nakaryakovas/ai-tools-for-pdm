## Цель проекта
Создать простое веб‑приложение для планирования и выгула Бориса и контроля кормления.

## Целевая аудитория
Пользователи организации где живет собака Борис, которым нужен простой инструмент для планирования без регистрации и сложных функций.

**Задачи:**
* [x] Реализовать заполнение свободных слотов для выгула Бориса с записью в базу данных
* [x] Реализовать отображение занятых слотов с выводом ошибки при попытке заполнить уже занятого слот

**Проверка:**

* Занятый слот показывает ФИО первоначального сотрудника.
