# Кто выгуливает Бориса

Приложение предназначено для записи на прогулку Бориса, проставления отметок о кормлении

## Возможности

- Видно занятые слоты с уже записанными сотрудникам
- Видны свободные слоты для возможности записи
- Запись на прогулку в свободные слоты
- Запись о кормлении

## Технологии

- Node.js-приложение
- SQLite-база данных
- SQLite-драйвер для Node.js

## Быстрый запуск

Для запуска приложения локально используйте команду `npm start`.
В браузере введи ссылку http://localhost:3000/


## Запуск

При запуске приложения отображается страница с текущей датой с занятыми и свободными слотами для выгула Бориса, а также информация о последнем кормлении Бориса.
